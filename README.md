## English

Moodle media player of the [EduPlay Moodle Suite](https://github.com/eduplay-moodle-suite): turns `https://eduplay.rnp.br/app/video/{id}` links into the official [EduPlay](https://eduplay.rnp.br/) player (responsive iframe) through the Media API and the Multimedia plugins filter. Requires [`local_eduplay`](https://github.com/eduplay-moodle-suite/moodle-local_eduplay). Supports Moodle 4.5 LTS and 5.3 LTS.

> Unofficial project: no affiliation with RNP, EduPlay or Moodle HQ.

Install `local_eduplay` in `local/eduplay`, then this repository in `media/player/eduplay` (`public/` prefix on Moodle 5.1+), and visit *Site administration > Notifications*.

## Português (Brasil)

Media player do Moodle da [EduPlay Moodle Suite](https://github.com/eduplay-moodle-suite): transforma links `https://eduplay.rnp.br/app/video/{id}` no player oficial do [EduPlay](https://eduplay.rnp.br/) (iframe responsivo) via Media API e filtro de Plugins de multimídia. Requer o [`local_eduplay`](https://github.com/eduplay-moodle-suite/moodle-local_eduplay). Suporta Moodle 4.5 LTS e 5.3 LTS.

> Projeto não oficial: sem afiliação com a RNP, o EduPlay ou o Moodle HQ.

Instale o `local_eduplay` em `local/eduplay` e depois este repositório em `media/player/eduplay` (prefixo `public/` no Moodle 5.1+), e acesse *Administração do site > Notificações*.
