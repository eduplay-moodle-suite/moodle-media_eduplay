Configuration
=============

1. Go to *Site administration* > *Plugins* > *Media players* > *Manage media players* and make sure **EduPlay** is enabled.
2. Go to *Site administration* > *Plugins* > *Filters* > *Manage filters* and make sure **Multimedia plugins** is enabled (it is by default).

The plugin has no settings of its own. Metadata cache and security rules are configured in ``local_eduplay``.

Privacy
-------

The plugin stores no personal data. The browser of the viewer loads the official player directly from ``eduplay.rnp.br``, under the privacy policy of EduPlay itself.
