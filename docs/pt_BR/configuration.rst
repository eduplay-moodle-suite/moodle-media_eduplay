Configuração
============

1. Acesse *Administração do site* > *Plugins* > *Media players* > *Gerenciar media players* e verifique se o **EduPlay** está habilitado.
2. Acesse *Administração do site* > *Plugins* > *Filtros* > *Gerenciar filtros* e verifique se **Plugins de multimídia** está habilitado (é o padrão).

O plugin não tem configurações próprias. Cache de metadados e regras de segurança são configurados no ``local_eduplay``.

Privacidade
-----------

O plugin não armazena dados pessoais. O navegador do usuário carrega o player oficial diretamente de ``eduplay.rnp.br``, sob a política de privacidade do próprio EduPlay.
